# Milestone 4 Optimization Report

## Reproducible Retrieval & Ingestion Benchmark

Empirical benchmark measurements generated by `scripts/run_retrieval_experiment.py` across 10 evaluation queries spanning HR, Technology, and Finance knowledge domains.

- **Artifact File**: `docs/results/m4_retrieval_experiment.json`
- **Embedding Model**: `all-MiniLM-L6-v2` (384-dimensional dense vectors)

## Empirical Configuration Benchmarks

| Parameter | Config A (Compact) | Config B (Selected Baseline) | Config C (Large Context) |
|-----------|--------------------|------------------------------|--------------------------|
| **Chunk Size (Tokens)** | 300 | **500** | 700 |
| **Chunk Overlap (Tokens)** | 30 | **50** | 70 |

## Parameter Selection Rationale
- **Config B (500 tokens / 50 overlap / Top-K = 5)** was selected as the operational default.
- Provides a balanced context window (5 chunks) for LLM synthesis while maintaining robust hit rate (70.0%) and low retrieval latency (~20.2 ms).
